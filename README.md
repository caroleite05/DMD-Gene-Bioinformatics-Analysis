# DMD Gene — Bioinformatics Analysis

This project focuses on the DMD gene, which encodes dystrophin, a protein essential for the structure and function of skeletal muscle.

The work explores homologous protein sequences and their evolutionary relationships through phylogenetic analysis, providing a broader understanding of the evolutionary context of dystrophin.

<br>

## Objectives
- Explore homologous protein sequences related to DMD.
- Perform comparative sequence analysis.
- Generate phylogenetic trees.
- Investigate the evolutionary relationships between homologous proteins.
